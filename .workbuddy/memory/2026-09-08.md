### 高德地图不渲染的常见原因（必须排查）
- 容器尺寸 = 0（最常见）：grid 内的 `1fr` 列被压缩、Tailwind 父容器 `display:none` 或 `overflow:hidden` 截断
- Key Referer 白名单没配 `localhost:3000`（高德 API 直接拒绝）
- Key 没开通 Web端 JS API 权限（控制台报 INVALID_USER_KEY）
- `script.onload = initMap` 直接跑，AMap 全局对象还没挂载
- 容器不在视口内时，AMap 可能不渲染（需要 `map.setFitView()` 强制重绘）
