- 机票字段：airlineCompany / flightNumber / departureTime / arrivalTime / departureAirport / arrivalAirport / totalDuration / basePrice / totalTax / cabinClass / remainingSeats
- 时间格式 "2026-10-20 03:04"，duration "3时41分"

### 关键坑：tuniu 可执行文件定位
- tuniu 装在 `C:\Users\Administrator\.workbuddy\binaries\node\versions\22.22.2-2\`（workbuddy 托管 node 目录）

- 最终方案：直接调 `node.exe` + `node_modules/tuniu-cli/bin/tuniu.js`，绕开 .cmd
