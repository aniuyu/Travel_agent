### 关键经验（项目约定）
1. deepagents 0.6.12 中 subagent 的 `skills` 字段是「技能目录路径列表」，相对 backend root（如 "skills/flight_search"），不是技能名。
2. 技能文件需放 content/skills/（LazyFilesystemBackend 会复制到 D:/agent_files/<thread>/skills/）。
3. SubAgent 是 TypedDict：必填 name/description/system_prompt，可选 tools/model/skills。
4. 测试 agent 时，agent 必须在模块级（同步上下文）组装，因为 travily_search.get_tools() 内部用了 asyncio.run()，在运行中的事件循环里会报错。
5. 本机 WebSocket 测试需 NO_PROXY 绕过代理。
6. **用户启动链路是 langgraph dev + pnpm dev**（langgraph.json 把 agent.py:agent 注册为 graph，前端通过 NEXT_PUBLIC_API_URL=http://localhost:2024 连）。**今后接此类项目第一件事要确认启动链路，不能假设是 FastAPI + WebSocket。**

### 第十轮：解决酒店图片不显示问题
- 现象：数据通了（7家真实酒店），但前端看不到图片
- 根因（两处）：
  1. 后端 `_format_hotel_result` 图片行用了 3 空格缩进 `   ![img](url)`，易被 Markdown 解析器误判，且 img 的 alt 用了固定「酒店图片」
  2. 前端 `markdown-text.tsx` 的 react-markdown `defaultComponents` 没有显式定义 `img` 组件，途牛 CDN 图片可能被 referrer 拦截
- 修复：
  1. 后端图片行改为无缩进标准语法 `![酒店名](url)`，meta/点评缩进也统一去掉
  2. 前端加 `img` 组件：`loading="lazy"` + `referrerPolicy="no-referrer"` + `max-h-64 rounded-lg`，a 标签加 target=_blank
- 前端 `tsc --noEmit` 通过
- 经验：react-markdown 的 img 默认不带 referrerPolicy，第三方 CDN 图片（途牛 tuniucdn.com）可能因防盗链 403，需显式加 referrerPolicy="no-referrer"

### 第十三轮：修复 `name 'Path' is not defined` 连锁错误
- 现象：查火车票时报 `Error: name 'Path' is not defined`，进而 AI 退而求其次用 tavily_search，又触发 429 TPM 限流，最终只能拼凑"约318班、G7xxx"的模糊二手数据
- 根因：上一轮加 `_find_tuniu()` 时函数体里用了 `Path(...)`，但 `from pathlib import Path` 被错误地写进了 `_run_tuniu()` 函数体内（局部 import），导致 `_find_tuniu()` 运行时 Path 未定义
- 修复：`travel_mcp.py` 顶部补 `from pathlib import Path`，删除 `_run_tuniu()` 里的局部 import
- 验证：火车票/酒店/航班三工具全部正常返回真实数据
- 教训：**每次改完代码必须实际 import + 调用一遍工具验证**，不能只改不测；局部 import 很容易被遗漏导致运行时 NameError
