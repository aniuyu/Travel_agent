# 行程单生成技能（itinerary-generator）

## 目标

把主 Agent 或行程子 Agent 汇总出来的「交通候选 + 住宿候选」，整合成一份**结构清晰、可直接执行**的行程单。绝不虚构任何航班、酒店、时间、价格——所有内容必须来自前面工具的真实返回结果。

## 一、行程单必须包含的要素

| 区块 | 必填字段 | 说明 |
|------|---------|------|
| 概览 | 出行人、目的地、日期范围、出行主题 | 一句话行程摘要 |
| 交通（去程） | 航班号/车次、航司、起降时间、时长、价格、直飞/中转 | 从 `search_flights` 结果选取 |
| 交通（返程，如有） | 同上 | 往返票才需要 |
| 住宿 | 酒店名、位置、评分、价格、入住/退房日期 | 从 `search_hotels` 结果选取 |
| 每日安排 | 按天列出活动建议 | 结合景点/餐饮，标注「建议」而非硬性 |
| 预算汇总 | 交通合计 + 住宿合计 + 总计 | 仅用工具返回的价格累加 |
| 出行提示 | 证件、天气、行李、改签等提醒 | 通用提醒即可 |

## 二、生成规则

1. **数据来源唯一**：只能引用前面工具（`search_flights` / `search_hotels`）返回的字段，禁止自己补造航班号、价格、评分。
2. **比选落地**：在「方案比选」阶段给用户推荐的首选方案，直接写进行程单主方案，备选方案放在末尾「备选」小节。
3. **价格标注**：所有价格注明「参考价，以实际出票/预订为准」。
4. **输出格式**：优先 Markdown；若用户要求可下载，则生成 `.md` 文件（可用 `write` 工具落盘），文件名形如 `行程单_上海_2026-09-10.md`。

## 三、输出模板（Markdown）

```markdown
# ✈️ 行程单 · {目的地} {出发日期}

**出行人**：{人数}人　**主题**：{商务/度假/亲子...}
**日期**：{出发日期} ~ {返程日期/退房日期}

## 一、交通方案
| 日期 | 航班 | 航司 | 起降 | 时长 | 类型 | 参考价 |
|------|------|------|------|------|------|--------|
| ... | ... | ... | ... | ... | ... | ... |

## 二、住宿方案
| 日期 | 酒店 | 位置 | 评分 | 参考价/晚 |
|------|------|------|------|-----------|
| ... | ... | ... | ... | ... |

## 三、每日安排
- **Day 1**：...
- **Day 2**：...

## 四、预算汇总
- 交通合计：¥xxx
- 住宿合计：¥xxx
- **总计：¥xxx**（参考价）

## 五、出行提示
- 请携带有效身份证件
- 建议提前 2 小时到达机场办理值机
- 以上均为参考价，以实时预订为准

## 备选方案
- 备选航班 / 备选酒店 ...
```

## 四、红线

- ❌ 绝不虚构航班、酒店、价格、评分。
- ❌ 数据缺失时如实标注「待确认」，不得编造。
- ✅ 行程单是「方案呈现」，不代替真实下单；实际预订需用户确认后通过预订服务完成。
