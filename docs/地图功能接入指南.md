# 地图功能接入指南（高德地图）

> 为「飞云通旅游平台」增加地图展示能力：酒店/景点打点、两点路线、多日行程串联、天气/周边叠加。

---

## 一、你还需要准备什么（就 1 件事）

**去高德开放平台申请一个 Key**（我已经把代码骨架都写好了，你只需要 Key）：

1. 打开高德开放平台：**https://lbs.amap.com/**
2. 注册 / 登录（个人实名认证即可，免费）
3. 进入「控制台」→「应用管理」→「创建新应用」
4. 添加 Key，**服务平台选择「Web端（JS API）」**
5. 创建后会得到两个东西：
   - **Key**（一串字母数字，形如 `xxxxxxxxxxxx`）
   - **安全密钥 securityJsCode**（推荐一并获取，在控制台「安全密钥」页面）

> ⚠️ 重要：在控制台给这个 Key 配置 **Referer 白名单**，填你前端的访问域名（本地开发填 `localhost` 或留空测试），否则 Key 可能被他人盗用。

---

## 二、配置 Key（我已经留好占位符）

把 Key 填入前端环境变量文件 `sub_projects/agent-chat-ui/.env`：

```bash
NEXT_PUBLIC_AMAP_KEY=你的高德Key
NEXT_PUBLIC_AMAP_SECURITY_CODE=你的安全密钥
```

> 后端如果也想用真实地理编码（推荐），在项目根目录 `.env` 加：
> ```bash
> AMAP_KEY=你的高德Key
> ```

## 四、如何触发地图（对话示例）

地图功能由 AI 判断触发。你可以这样问：

| 想展示 | 示例问法 |
|--------|---------|
| 酒店位置打点 | "帮我把刚才查到的 3 家酒店在地图上标出来" |
| 两点路线 | "从南京南站到上海虹桥的驾车路线，帮我画出来" |
| 多日行程串联 | "帮我规划上海 2 日游，并生成行程地图" |
| 景点分布 | "外滩附近有哪些景点，在地图上标一下" |

AI 会调用 `geocode` 拿坐标，再用 `build_map` 输出地图数据。

## 六、合规说明（重要）

- 使用高德地图（合规白名单内），坐标用 **GCJ-02 火星坐标**（高德原生坐标系，无需转换）。
- **不要**把 Key 硬编码进 `.tsx` 文件，务必走环境变量，并在高德后台配 Referer 白名单。
- 地图上不标注军事禁区、涉密点位等敏感信息。
