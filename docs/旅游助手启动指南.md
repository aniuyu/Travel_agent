# 智能旅游助手 · 启动与测试指南

> 本项目在 `ai_agent2` 内新增了一个完整的「智能旅游助手」能力，包含航班查询、酒店推荐两大技能，可独立运行、即开即用。

## 二、启动步骤

### 1. 启动后端（FastAPI）

```bash
# 在项目根目录 ai_agent2 下，使用你的虚拟环境
.venv/Scripts/python.exe app.py
```

启动成功后访问 `http://127.0.0.1:8000/` 会返回 `"Hello, World!"`。

> 说明：
> - 旅游助手默认开启（`USE_TRAVEL=true`）。如需关闭，在 `.env` 里加 `USE_TRAVEL=false`。
> - 航班/酒店目前用 Mock 数据（无需 API Key）。接入真实数据后，在 `.env` 设置
>   `TRAVEL_MCP_URL=你的MCP服务地址` 即可自动切换到真实服务。

### 2. 打开前端页面

**方式 A（推荐，零依赖）**：直接用浏览器打开

```
frontend/index.html
```

（双击打开即可，页面会自动通过 WebSocket 连接 `ws://127.0.0.1:8000/chat`）

**方式 B（可选，起本地静态服务器）**：

```bash
cd frontend
# 用 Python 起一个静态服务器（任选其一）
python -m http.server 3000
# 然后浏览器访问 http://127.0.0.1:3000
```

## 三、测试方法

### 1. 直接对话测试（最直观）

打开前端页面后，在输入框输入：

```
帮我订一张2026年9月10日从北京到上海的机票，经济舱，1个人，单程
```

或

```
帮我订2026年9月10日入住、9月11日退房的上海酒店，预算500以内，近市中心
```

AI 会路由到旅游子代理，调用工具并返回航班/酒店结果 + 综合建议。

### 2. 命令行测试（已为你写好脚本）

```bash
# 测试工具独立运行
.venv/Scripts/python.exe content/mcps/travel_mcp.py

# 测试旅游子代理闭环（子代理直接调用工具）
.venv/Scripts/python.exe test_travel_subagent.py

# 测试主代理路由（主代理 → travel-agent → 调用工具）
.venv/Scripts/python.exe test_travel_route.py

# 测试完整 WebSocket 链路（模拟前端）
.venv/Scripts/python.exe test_travel_e2e.py
```

> 注意：`test_travel_e2e.py` 需要设置代理绕过（本机 WebSocket 不走代理）：
> 如果报代理错误，用 `NO_PROXY="127.0.0.1,localhost" .venv/Scripts/python.exe test_travel_e2e.py` 运行。

## 四、接入真实航班/酒店 API（可选）

当前 `search_flights` / `search_hotels` 返回 Mock 数据。接入真实数据的两种方式：

1. **方式 A**：直接改 `content/mcps/travel_mcp.py` 里两个 `@tool` 函数体，把返回逻辑换成对真实第三方 API（如飞常准、Amadeus、携程开放平台）的 HTTP 调用。
2. **方式 B**：在 `.env` 里配置 `TRAVEL_MCP_URL`，`get_tools()` 会自动通过 `MultiServerMCPClient` 连接真实 MCP 服务（见 `travel_mcp.py` 中的 `_REAL_MCP_CONFIG`）。

## 五、常见问题

| 问题 | 解决 |
|------|------|
| 启动时打印 `Minio创建存储桶失败` | 可忽略，MinIO 容器未启动不影响旅游助手（已优雅降级） |
| 前端显示"未连接" | 确认后端已启动，端口 8000 未被占用 |
| 想关闭旅游助手 | `.env` 加 `USE_TRAVEL=false` |
| 想换 logo | 改 `frontend/index.html` 顶部 `.logo` 里的 emoji（✈）为你自己的图片 |
